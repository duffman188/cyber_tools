# ✅ Green Team Test Checklist

## 🔐 Login Page
- [ ] Can I create an account?
- [ ] Does the password require symbols, uppercase, and > 8 chars?
- [ ] Does the "forgot password" flow work?

## 📊 Dashboard / Main Service
- [ ] Are buttons and navigation working?
- [ ] Any broken links/images?
- [ ] Are there clear instructions?

## 🛑 Edge Cases
- [ ] What happens if I enter bad data?
- [ ] Does an error message appear?
- [ ] Can I see information I shouldn’t (e.g., admin settings)?
